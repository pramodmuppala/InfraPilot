Actions

Prompt Help

Use clear desired-state prompts with an explicit instance count.

Examples

  • Deploy a scalable Java app with 1 instance
  • Deploy a scalable Java app with 5 instances and auto-recovery
  • Increase JVMs to 5
  • Scale Tomcats to 4
  • Reduce JVMs to 1
  • Scale instances to 5 with auto-recovery

Supported terms

JVMs, Tomcats, instances, and nodes are treated as equivalent scaling targets.

Recommended style

Use a verb plus a target count, such as “Increase JVMs to 5” or “Reduce Tomcats to 1”.

Supported range

Current supported instance range is 1 to 5. Requests outside this range are rejected during validation.

Avoid

  • Add more JVMs
  • Scale up a bit
  • Make it bigger
  • Optimize deployment
